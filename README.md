# W8Pool｜校招求职岗位池

> 汇集机会，沉淀选择，抵达理想。

W8Pool 是一款面向校招求职场景的岗位信息与行动管理工具。它以“岗位池”为核心，把分散在招聘网站、社群、表格、朋友转发和 AI 整理结果中的岗位线索，沉淀为可筛选、可追踪、可执行的个人求职工作台。

[在线体验](https://w8-pool.pages.dev/) · [访客模式](https://w8-pool.pages.dev/preview) · [GitHub 仓库](https://github.com/weiting1211wendy-lab/w8pool)

如果这个项目对你有启发，欢迎点一个 Star ⭐

## 项目亮点

- **从信息管理到行动推进**：不只收藏岗位，还能把重点岗位转化为任务、目标日期、投递进度和材料准备。
- **个人判断与共享线索分离**：群组岗位池用于共享机会，个人筛选、备注、Priority、投递进度始终保持私有。
- **访客模式可直接体验**：无需注册即可查看完整功能流程，所有访客数据均为虚构演示数据。
- **围绕真实使用持续迭代**：补充批量导入、重复拦截、回收站、云端回滚、成就统计与日程联动等数据安全和效率功能。
- **AI 协作开发实践**：由开发者完成需求拆解、信息架构、交互设计和功能验收，并借助 Codex、OpenCode 等 AI coding 工具完成开发迭代。

## 核心功能

| 模块 | 说明 |
| --- | --- |
| 我的岗位池 | 记录岗位信息，支持搜索、筛选、分组、排序、状态管理、Priority 星级、个人备注与岗位标签 |
| 任务管理 | 将重点岗位拆分为投递、笔试、面试、材料准备和跟进事项，并按公司、岗位与目标日期推进 |
| 网申材料管理 | 按岗位类型维护个人材料模块，支持预览、复制和多版本复用 |
| 群组岗位池 | 与同学或伙伴共享岗位线索；个人筛选、备注、投递进度保持私有 |
| 首页成就与日程 | 按日期查看新增岗位、筛选动作、进度更新等推进记录；任务目标日期自动生成日程 |
| 数据安全 | 支持账户备份、恢复预览、云端快照、回滚和个人岗位回收站 |
| 访客模式 | 使用独立的虚构演示数据体验完整功能，不读取、不写入真实账户数据 |

## 开发中功能

- **智巡岗位 Robot**：根据关键词与检索规则抓取岗位线索，进入待审核池后再由用户决定是否纳入岗位池。
- **社区岗位池**：面向不同专业与求职方向聚合公开岗位线索。
- **网申预填小助手**：将目标岗位与个人材料版本组合为可核对、可编辑的网申草稿。

## 技术栈

- 前端：React、TypeScript、Vite
- 部署：Cloudflare Pages
- 后端：Cloudflare Pages Functions
- 数据库：Cloudflare D1
- AI 协作：Codex、OpenCode 等 AI coding 工具

## 产品思路

W8Pool 的设计重点不是“再做一个表格”，而是把校招过程中的信息流和行动流串起来：

```text
获取岗位线索 → 沉淀个人岗位池 → 筛选与优先级判断 → 任务推进 → 材料复用 → 数据备份与恢复
```

在这个流程中，共享岗位池解决“机会从哪里来”，我的岗位池解决“我怎么判断”，任务管理解决“下一步做什么”，网申材料管理解决“重复填写如何复用”，数据安全机制解决“长期使用如何不丢数据”。

## Cloudflare 配置

公开仓库中不提交真实 `wrangler.jsonc`。如需自行部署：

1. 复制 `wrangler.example.jsonc` 为 `wrangler.jsonc`；
2. 在 Cloudflare 创建 Pages 项目和 D1 数据库；
3. 将 `database_id` 替换为自己的 D1 数据库 ID；
4. 执行数据库迁移；
5. 部署到 Cloudflare Pages。

```bash
cp wrangler.example.jsonc wrangler.jsonc
npm run cf:d1:migrate
npx wrangler pages deploy dist
```

## 数据与隐私说明

- 仓库不包含真实用户数据、个人岗位备份、Cloudflare 账号凭据或 D1 真实数据库 ID。
- 访客模式数据为虚构演示数据，仅用于展示产品流程。
- 工作台数据按账户隔离保存；群组岗位池中的共享岗位与个人筛选、备注、投递进度分离。
- `wrangler.example.jsonc` 仅提供部署配置模板，真实 `wrangler.jsonc` 已被 `.gitignore` 排除。

## 项目背景

该项目由开发者基于真实校招求职管理需求独立设计，并借助 AI coding 工具完成开发迭代。项目重点不在于单一技术炫技，而在于通过产品化方式梳理信息流、行动流和数据边界，将“岗位记录”扩展为“岗位获取、筛选决策、任务推进、材料复用与协作共享”的完整闭环。
